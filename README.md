# 非遗学徒成长档案

本仓库保存非遗学徒成长服务的领域资料、事件契约与服务核心实现，
供业务团队在统一语义上继续建设。

## 内容结构

- `contracts/domain.schema.json`：领域事件信封——追溯字段、聚合类型和事件名称。
- `src/events.js`：事件目录，定义每个事件作用的聚合与 payload 必填字段。
- `src/validator.js`：信封校验（字段、枚举、版本、时间格式），以契约为准。
- `src/archive.js`：服务核心 `GrowthArchive`，接收事件并执行领域不变量
  （多方评价认定、分歧复核、受限工序脱敏、津贴去重、带教负荷、成绩保留与转认）。
- `src/views.js`：角色视图——企业只见受限工序的完成结论，管理部门可见汇总报表。
- `data/sample.json`：单条样例记录；`data/sample-flow.json`：从报名到就业的完整样例流程。
- `docs/domain-model.md`：领域模型说明（聚合、事件、不变量、角色权限、补录约定）。
- `tests/`：契约同步校验与全部不变量的行为测试。

## 领域边界

当前资料围绕技艺谱系、课程版本、师徒关系、实训作品、工序能力、考核证据、
津贴、试岗与去向整理。事件一旦被接收，其标识、发生时间和版本不应被原地
改写；业务更正应产生后继记录。涉及个人、机构或商业敏感信息时，调用方只
读取完成职责所必需的字段；传统核心（受限）工序在系统中只记录完成结论与
保管位置，技法细节不入档，用工企业无权查看受限内容。
