# 非遗学徒成长档案

东城区非遗学徒成长服务的领域资料与最小事件约定，供业务团队在统一语义上继续建设。服务串联技艺谱系、课程版本、师徒关系、实训作品、工序能力、考核证据、津贴、试岗与去向，覆盖学员从一次实训到可申请岗位、再到正式就业的完整路径。

## 内容导航

- `contracts/domain.schema.json`：领域事件契约——信封字段、28 种事件、12 类聚合、`source` 追溯块、受限核心步骤载荷约束与多方评价结构。
- `data/sample.json`：单条最小样例。
- `data/sample-lifecycle.json`：两个项目（都一处烧麦 / 大北人像摄影）、两名学徒的全生命周期事件流，涵盖多方分歧复核、线下补录、休学复课、转项目、师傅退出、课程升版、试岗录用。
- `src/validator.js`：事件结构校验与事件流不变量（事件-聚合归属、版本单调、津贴幂等键、来源凭证去重、补录字段、更正引用、受限细节拒收）。
- `src/projection.js`：把事件流折叠为当前状态——师徒状态与师傅负荷、能力状态机、津贴累计、成绩转认、企业脱敏视图、培训投入产出报表。
- `tests/contract.test.js`：13 项测试，验证样例与上述规则。
- `docs/domain.md`：领域边界、事件目录、能力认定/复核规则、受限内容管理、成绩保留与可转认、权限视图。

## 领域要点

事件一旦被接收，其标识、发生时间和版本不应被原地改写；业务更正产生携带 `correction_of_event_id` 的后继记录。所有接入记录（含线下补录）统一使用 `source` 追溯块，可从档案回溯到学校名册、工作室口传记录、企业评价或纸质凭证。

传统核心步骤只记录完成结论和保管位置，手法/配方/参数不进入事件流，企业视图不可见受限细节。能力认定不来自一次打卡：师傅、学校、企业的评价可分歧并进入复核，复核可作“限定范围认定”。休学、转项目、师傅退出、课程升版均保留既往成绩并通过 `CREDIT_TRANSFERRED` 明确可转认范围；津贴按幂等键去重，线上与线下补录同键空间；师傅带教负荷随挂起/结束/退出释放、恢复/指派占用，且不得超额。
